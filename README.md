## 📖 项目简介

《时约》是一款专为安卓系统打造的**非 iOS 风格、极致纯粹的高颜值纪念日 / 倒数日应用**。  
设计灵感源自平面设计史上的**瑞士国际主义平面排版风格（Swiss Typographic Style）**，告别花哨的圆角高光与拟物毛玻璃，仅靠巨幅纯黑/纯白粗体数字与极细几何分割线，呈现出如同高端画册般的视觉冲击力与理性美感。

同时，应用深度融合了现代生活所需的全套实用功能：**内置 20+ 贴纸的遮脸 P 图纪念卡册**、**2×2 原生安卓桌面小组件**、**中国传统农历（阴历）精准推算**、**一键写入手机系统日历**以及**瑞士极简朋友圈海报生成器**。

---

## ✨ 核心功能特色

### 1. 瑞士极简双模看板 (Swiss High-Contrast UI)
- **巨幅焦点看板**：置顶展示最重要的纪念日，大数字视觉冲击力拉满。
- **双模极简切换**：一键在 `[DARK]`（建筑哑光纯黑，OLED 屏幕极致省电）与 `[LIGHT]`（画册纯白）间无缝切换。
- **年度时光进度条**：直观展示本年度时间走过的百分比进度。

### 2. 📸 纪念卡册 & 20+ 款贴纸遮脸 P 图神器
- **每条记录支持上传最多 3 张现场照片**，提供「原图高清」与「压缩标清」双选项。
- **照片背后的故事备注**：每张照片专属文字记录，细述那天发生的故事。
- **内置 20 款精选卡通贴纸**：
  - **遮脸神器**：🕶️ 酷炫墨镜、😷 纯白医用口罩、🐱 软萌猫咪、🐶 元气柴犬、🐻 棕熊抱抱、🐼 憨萌熊猫、🐰 萌兔垂耳、🦊 赤狐面具、🥸 搞怪大胡子眼镜、🎭 舞会假面；
  - **趣味点缀**：👑 黄金王冠、🎀 粉色蝴蝶结、🌸 浪漫樱花、💖 璀璨爱心、🌟 闪耀星芒、🎩 绅士礼帽、🍓 奶油草莓、🌈 晴空彩虹、🎈 彩色气球、🔥 热烈之火；
- **丝滑交互**：支持手指随意拖动贴纸遮盖人脸、自由缩放大小（0.3x ~ 2.5x），一键烘焙合成。

### 3. 📱 2×2 原生安卓桌面小组件 (Desktop Widget)
- 完美契合华为/荣耀等主流安卓桌面的 2×2 大圆角磨砂微件卡片。
- 自动同步展示 App 内置顶的焦点纪念日与天数，无需打开应用，在手机桌面上随时查看。
- 轻触卡片一秒直达应用。

### 4. 🌙 中国传统农历（阴历）精准换算
- 支持公历（阳历）与农历（阴历）自由切换。
- 农历支持正月至腊月、初一至三十，系统每年自动推算对应的下一个公历倒数日，完美适用于长辈农历生日与传统节日。

### 5. 🗓️ 一键同步系统日历与闹钟
- 支持一键导出并直接写入手机系统自带日历（`.ics` 国际标准日程协议），并自动设定纪念日当天早晨 9:00 闹钟提醒。

### 6. 🖼️ 极简朋友圈海报一键导出
- 自动以瑞士平面排版风格生成 1080×1440 高清海报大图，包含大数字、标题、现场照片与专属品牌印记，支持一键保存至手机相册分享至社交平台。

### 7. 🔒 100% 离线隐私安全与数据备份
- 数据全部保存在用户本地，零后台、零数据上传、无广告侵扰。
- 支持一键导出 / 导入标准 JSON 备份文件，换机迁移零门槛。

## 📂 项目结构

```
时约/
├── index.html                   # 现代化单页应用核心源码 (完整逻辑、样式与算法)
├── manifest.json                # PWA 独立应用配置清单
├── favicon.png                  # 高清图标 (Favicon)
├── icon-192.png                 # 192x192 启动图标
├── icon-512.png                 # 512x512 高清大图
├── 时约.apk                     # 已编译并签名的标准安卓独立安装包
├── android/                     # 安卓原生 Native 工程源码
│   └── src/main/
│       ├── AndroidManifest.xml  # 应用清单配置 (仅申请网络、日历读写与桌面微件)
│       ├── java/com/shiyue/app/
│       │   ├── MainActivity.java        # 主 Activity 与 Native JSBridge 通信桥梁
│       │   └── ShiYueWidgetProvider.java # 2x2 原生桌面小组件 Provider
│       ├── assets/              # 打包入 APK 的应用前端静态资源
│       └── res/
│           ├── layout/          # 桌面小组件布局 (widget_shiyue.xml)
│           ├── xml/             # 小组件元数据配置 (widget_info.xml)
│           └── drawable/        # 小组件背景与启动图标
└── .builder/                    # 自动化打包与编译工具链
    ├── build.py                 # 一键免 Android Studio 极速自动化编译打包脚本
    └── shiyue.jks               # 专属独立正式发布签名证书 (Release Keystore)
```

## 🛠️ 如何构建与运行

本项目包含专为开发者与极客打造的**微型自动化构建系统**（无须安装庞大的 15GB Android Studio）：

```bash
# 运行一键构建脚本（全自动完成编译、Dex、资源打包与签名）
python .builder/build.py
```

构建完成后将在项目根目录与桌面生成最终的 `时约.apk`。
